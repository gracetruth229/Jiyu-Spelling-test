영어 단어 받아쓰기

듣고 → 스펠링 입력 → 음성 채점

1. 단어 입력

0개

1~800번 단어 800개가 이미 들어 있습니다. 그대로 쓰시면 되고, 다른 단어로 공부하려면 엑셀을 올리세요. 직접 만든 엑셀도 단어 열 + 뜻 열만 있으면 되고, 열 순서가 바뀌거나 번호 열이 앞에 있어도 자동으로 찾습니다. 첫 줄 머리글은 건너뜁니다. 파일을 입력창에 끌어다 놓아도 됩니다.

입력한 목록은 이 브라우저에 자동 저장됩니다.

2. 출제 설정

목록에 ⭐ 가 붙은 것이 가장 자연스러운 목소리입니다. 하나뿐이라 아쉽다면 Microsoft Edge 로 열어 보세요. 훨씬 사람 같은 한국어 목소리가 여러 개 나타납니다.

범위는 엑셀 번호(A열) 기준입니다. 601-630 처럼 적으면 그 번호의 단어만 출제합니다. 1-50, 601-630 처럼 여러 구간을 쉼표로 이어 붙이거나, 7 처럼 한 개만 적어도 됩니다. 비워 두면 전체에서 출제합니다. (번호가 없는 목록은 위에서부터 1, 2, 3… 순번으로 셉니다)

첫 실행 시 브라우저가 음성을 준비하는 데 1~2초 걸릴 수 있습니다.
