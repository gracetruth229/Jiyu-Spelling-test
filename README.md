# 🎧 영어 단어 받아쓰기

한국어 뜻을 음성으로 들려주면 영어 스펠링을 입력해 맞히는 단어 학습 웹앱입니다.
정답이면 칭찬, 틀리면 다시 해보라는 안내를 **음성으로** 들려줍니다.

**👉 [바로 사용하기](https://gracetruth229.github.io/Jiyu-Spelling-test/)**

---

## 특징

- **설치 불필요** — HTML 파일 하나로 동작합니다. 서버도, 인터넷도 필요 없습니다.
  (본문 글꼴 Pretendard만 인터넷에서 받아오며, 오프라인이면 시스템 글꼴로 자연스럽게 대체됩니다)
- **두 가지 출제 방식**
  - 🇰🇷 한국어 뜻을 들려주면 → 영어 스펠링 입력 (기본)
  - 🇺🇸 영어 발음을 들려주면 → 스펠링 입력 (받아쓰기)
- **단어 200개 내장** — 601~800번(Day21~Day27)이 이미 들어 있어 아무것도 올리지 않고 바로 시작할 수 있습니다.
- **엑셀 / CSV 업로드** — 다른 단어로 공부할 때. 외부 라이브러리 없이 브라우저 내장 기능만으로 `.xlsx`를 직접 읽습니다.
- **번호 범위 출제** — `601-630` 처럼 적으면 그 번호의 단어만 출제합니다.
- **틀린 단어만 다시 풀기** — 결과 화면에서 오답만 모아 재출제.
- 단어 목록과 설정은 브라우저에 자동 저장됩니다.

## 사용법

1. `index.html`을 브라우저에서 엽니다. (Chrome / Edge / Safari 권장)
2. **601~800번 단어 200개가 이미 들어 있습니다.** 그대로 쓰셔도 되고, 다른 단어로 바꾸려면
   - 입력창에 `번호. 단어, 뜻` 형식으로 한 줄에 하나씩 직접 입력 (번호는 없어도 됩니다)
   - **📁 엑셀 / CSV 불러오기** 버튼으로 파일 선택
   - 파일을 입력창에 끌어다 놓기
   - **기본 단어 (601~800) 넣기** 버튼으로 언제든 되돌리기
3. 출제 방식과 문제 수를 정하고 **시작하기**를 누릅니다.
4. 들리는 뜻에 해당하는 영어 단어의 스펠링을 입력하고 `Enter`.

### 단축키

| 키 | 동작 |
|---|---|
| `Enter` (입력 후) | 정답 확인 |
| `Enter` (빈 칸에서) | 문제 다시 듣기 |
| `Enter` (채점 후) | 다음 문제 |

## 엑셀 양식

[`단어목록_양식.xlsx`](단어목록_양식.xlsx)를 내려받아 채워 넣으면 가장 간단합니다.

| 번호 | 단어 | 뜻 |
|---|---|---|
| 1 | vacation | 휴가 |
| 2 | client | 고객 |

- 첫 줄 머리글(`번호` / `단어` / `뜻`)은 자동으로 건너뜁니다.
- **번호 열(A열)은 범위 지정에 쓰입니다.** 설정의 `범위` 칸에 `601-630`을 적으면 그 번호의 단어만 출제합니다.
  여러 구간은 `1-50, 601-630` 처럼 쉼표로 잇고, 한 개만 볼 때는 `7` 처럼 적습니다.
  번호를 비워 두면 위에서부터 1, 2, 3… 순번으로 셉니다.
- 열 순서가 바뀌어도, 번호 열이 앞에 있어도 자동으로 찾아냅니다.
- 뜻에 쉼표가 들어가도 됩니다. (예: `휴가, 방학`)
- 빈 줄은 무시되고, 중복된 단어는 하나만 남습니다.
- 파일의 **첫 번째 시트**만 읽습니다.
- 한글 엑셀이 저장하는 CP949 인코딩 CSV도 자동으로 인식합니다.
- 예전 형식인 `.xls`는 지원하지 않습니다. `.xlsx` 또는 CSV로 저장해 주세요.

## 음성에 대해

브라우저 내장 음성합성(Web Speech API)을 사용합니다. 별도 설치나 API 키가 필요 없습니다.

한국어 뜻을 읽어주려면 **한국어 음성이 설치되어 있어야** 합니다.
Windows에서 소리가 나지 않으면 `설정 → 시간 및 언어 → 음성 → 음성 추가`에서 한국어를 설치하세요.
한국어 음성이 없으면 앱이 알려주고, 뜻을 글자로 보여주는 방식으로 자동 전환됩니다.
